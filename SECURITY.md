# Security policy

This viewer is designed for a trusted private network and a trusted server owner. It is not a multi-tenant hosting service. Read the deployment and trust-boundary guidance in [README.md](README.md) before use.

Do not include camera links, access codes, server passwords, private addresses or video in public issues. For a suspected vulnerability, use the repository's private vulnerability reporting option when available, or contact the maintainer privately through their GitHub profile. Please avoid publishing an exploit against live camera installations.

Updates are distributed as source releases in this repository. Back up your protected data directory, review changes, update the source and rebuild/restart. Version 1.x is the current release line.
